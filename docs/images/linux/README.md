# Снимки экрана: Linux

Каждый кадр — в двух темах: `light-<имя>.png` и `dark-<имя>.png`. Снято без оконного менеджера, поэтому у окна и
диалогов нет рамок и заголовков; служба обхода на этих кадрах — тестовая, данные «Авто» — пример.

| Имя | Что на кадре |
|---|---|
| `home-stopped` | прокси остановлен, кнопка «Подключить» |
| `home-connected` | «Прокси готов — откройте ссылку в Telegram» |
| `home-telegram` | «Telegram работает через прокси» |
| `home-error` | прокси не запустился: красный заголовок и сообщение |
| `home-menu` | меню «···»: ссылка, QR для телефона, новый секрет |
| `bypass`, `bypass-bottom` | «Обход DPI»: переключатель, стратегии, «Что выбрал Авто», исключения, свои стратегии |
| `bypass-restarting` | движок обхода упал и перезапускается |
| `bypass-error` | движок обхода отверг стратегию |
| `bypass-exclusions`, `bypass-exclusions-bottom` | редактор исключений |
| `finder-confirm` | подбор стратегии: предупреждение перед запуском |
| `finder-running-1`, `finder-running-2` | подбор идёт |
| `finder-done` | итог подбора: таблица и лучшая стратегия |
| `custom-editor` | новая своя стратегия: параметры, «Проверить», «Сохранить» |
| `diagnostics-before`, `diagnostics` | «Проверка соединения» до и после запуска, с вердиктом |
| `logs`, `logs-proxy`, `logs-service` | «Журналы»: приложение, прокси, обход DPI |
| `settings`, `settings-advanced` | «Настройки» и раздел «Дополнительно» |
| `settings-confirm` | подтверждение замены секрета |
| `qr` | QR-код для телефона в той же сети |
| `wizard-1`, `wizard-2`, `wizard-2-telegram`, `wizard-3`, `wizard-finished`, `wizard-fail` | мастер первого запуска: шаги, готово, сбой подключения |

`tray-icons.png` — значок в трее с цветной точкой состояния (зелёный, янтарный, серый, красный) на тёмной и светлой панели.
