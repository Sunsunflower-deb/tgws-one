# TgwsOne на Android

> Черновик документации. Разделы «Обход DPI», «Подбор стратегии», «Авто» — в разработке (задачи E3.x/E4.x плана).

## Установка
- Скачайте APK со страницы Releases проекта (пока — артефакт сборки CI).
- Установите файл вручную или командой `adb install <файл>.apk`.
- Требуется Android 8.0 или новее (minSdk 26). Собирается под arm64-v8a, armeabi-v7a и x86_64.

## Подключение к Telegram
1. Откройте приложение — первый экран предложит подключить Telegram.
2. Нажмите кнопку: система откроет Telegram со ссылкой вида `tg://proxy?server=127.0.0.1&port=…&secret=…`.
3. Telegram покажет диалог добавления прокси — подтвердите.

Прокси работает только локально (127.0.0.1): трафик Telegram идёт через движок на телефоне, без root.

## Обход DPI (в разработке)
TgwsOne на Android обходит фильтрацию собственным слоем внутри движка (на десктопе это делает zapret2). Доступные приёмы: разрез ClientHello, разлад (disorder через TTL), фейковый ClientHello, срочный байт (oob), разрез TLS-записи (tlsrec).

## Настройки
Файл `files/tgwsone.ini`, секция `[android]`: `strategy` (стратегия или auto), `provider` (набор по оператору), `poolidle` (секунды простоя пула, по умолчанию 180).

## Батарея и работа в фоне
- Движок работает в foreground service с уведомлением; постоянного wake lock нет.
- Если система останавливает приложение: откройте системные настройки приложения (кнопка в приложении ведёт туда) и отключите оптимизацию батареи для TgwsOne.
- Агрессивные «экономители батареи» производителя (MIUI и др.) могут убивать сервис — в документации производителя найдите, как добавить приложение в исключения.

## Ограничения
- Без root; VpnService в первой версии нет.
- Обход применяется только к исходящим соединениям самого движка.
- Если на сети оператора ни одна стратегия не даёт связи — это честный результат: поможет только VPN.
