# История изменений

Формат: `## [версия] — дата`, далее короткий список изменений.
CI берёт раздел текущей версии и подставляет его в описание релиза.

## [1.0.5] — 2026-11-18

- Исправлена ошибка «TgwsOne requires Windows 10 or later» на Windows 11 26H2:
  `msiexec` отдаёт `VersionNT = 603`, поэтому проверка версии теперь идёт по реестру
  (`CurrentMajorVersionNumber`), с прежним условием как запасным.
- В README вернулись скриншоты и добавлена схема работы в начале.
- Внутри установки README тоже со схемой.

## [1.0.4] — 2026-11-18

- Обход DPI теперь **общесистемный**: задача `TgwsOne-Zapret` создаётся от SYSTEM
  с запуском при старте, поэтому работает для всех учётных записей на ПК.
- Настройки обхода общие — `C:\ProgramData\TgwsOne`; данные прокси у каждого пользователя свои.
- Добавлены условия установки: 64-битная Windows 10 или новее.
- Переключение обхода и смена стратегии в общем режиме — через UAC.

## [1.0.3] — 2026-11-18

- Своя иконка приложения (в exe, ярлыках и «Установка и удаление программ»).
- Ярлык на рабочем столе.
- Установка в `C:\Program Files\TgwsOne` (64-битный пакет).
- Исправления: окно не подтормаживает (опрос задачи zapret в фоне и с кешем),
  очистка списка `DC → IP` сохраняется, лог ограничен по размеру (файл и окно),
  ссылка `tg://` обновляется при смене порта, прокси перезапускается только при
  изменении его настроек.

## [1.0.2] — 2026-11-17

- Окно настроек: порт и хост, `DC → IP`, CF-прокси и HTTP/2, свои CF/Worker-домены,
  стратегия zapret, буфер/пул/лог, перегенерация секрета и копирование ссылки.
- В трее: «Сменить стратегию обхода DPI», «Копировать ссылку», «Лог zapret (winws)».

## [1.0.1] — 2026-11-17

- Исправлен баг: приложение и задача zapret писали данные в разные папки
  (`Program Files` против `%LOCALAPPDATA%`), из-за чего смена стратегии и остановка
  обхода не действовали.
- Вывод winws пишется в `logs\winws.log`.

## [1.0.0] — 2026-11-17

- Первый MSI: приложение, движок TG WS Proxy, zapret и списки внутри установщика.
- Установка в `Program Files`, ярлык в меню «Пуск», задача `TgwsOne-Zapret`.
